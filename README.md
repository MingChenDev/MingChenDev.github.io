# Ming Chen — Portfolio

A responsive, single-file portfolio website for GitHub Pages.

## Deploy to GitHub Pages

1. Create a **public** GitHub repository named `YOUR_USERNAME.github.io` (replace `YOUR_USERNAME` with your current GitHub username).
2. Upload `index.html` to the repository root, or push the files using Git.
3. Go to **Settings → Pages** and choose **Deploy from a branch**, branch `main`, folder `/ (root)`; save.
4. Visit `https://YOUR_USERNAME.github.io/` once deployment completes.

## Customize

- Replace the GitHub profile URL if your username changes.
- Add verified LinkedIn, email, resume, and project repository URLs.
- Update experience and project descriptions to match your final resume.

No dependencies or build tools required.
